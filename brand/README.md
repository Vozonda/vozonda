# Vozonda brand

The mark is a speech bubble (voz, the voices) holding the player's waveform (onda, the
wave): seven bars, the first four in green as already played, exactly like the player.
Chosen by the operator on 2026-10-03 from three rounds of concepts.

| File | Use |
|---|---|
| `vozonda-lockup.svg` / `-dark` | mark + wordmark: website header, README, GitHub, slides |
| `vozonda-mark.svg` / `-dark` | the mark alone where the name is already visible (app header) |
| `vozonda-icon.svg` / `-dark` | solid bubble, bars cut out: favicon, PWA/app icon, Nostr avatar, small sizes |
| `vozonda-mark-mono.svg` | one colour (`currentColor`), e.g. print, embroidery, watermarks |
| `vozonda-wordmark.svg` | the name alone, Source Serif 4 at weight 640, outlined |

## Rules

- **Mark or icon:** the outline mark from 24 px up; below 24 px always the solid icon
  (the outline bars blur together).
- **Colours** are the app's tokens: light ink `#1a1815`, green `#4a7300`, paper `#faf6ef`;
  dark ink `#ede8dd`, green `#84b832`, paper `#1f1d14`. The bars keep their split: four green,
  three ink. Never recolour single bars, never a gradient.
- **Clear space** around the mark: a quarter of its height on every side.
- **Name:** lowercase "vozonda" in the wordmark; "Vozonda" in sentences.
- **Do not** stretch, rotate, round the bubble's corners, add shadows or put the mark on a
  busy photo; on images use the icon in its own solid bubble.
- **Tagline:** "Turn sources into your podcast." / "Vozonda reads them, voices make waves,
  you listen."

Derived files (favicon, PWA icons, social preview, podcast cover, Nostr avatar) are
generated from these SVGs; edit the SVGs, not the derived files.
